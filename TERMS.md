## What this repository is — and is not

- It is a working computational core (Python standard library only) and
  a planner-level agent prototype, not a production EDA tool.
- All demo data in `data/` is **synthetic**. It is not real silicon
  data, not a PDK extract, and not a customer chip profile. Results on
  demo data do not predict the yield of any real chip.
- The agent observes, attributes, and recommends. It does not actuate a
  fab, change a process recipe, or make a tape-out decision. Any real
  tape-out, process, or yield decision remains a human decision, made
  with the user's own qualified tools and data.
